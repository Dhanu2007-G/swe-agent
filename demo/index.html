Architecture

From GitHub Issue to
Merged Pull Request

A LangGraph state machine orchestrates six specialized nodes. Each node is a pure async function, independently testable and traced via LangSmith.

🔍
1 · Read Issue
Fetches the GitHub issue via API. Runs an LLM-powered clarity check to determine if the issue has enough information to implement. Short-circuits on ambiguous issues instead of wasting compute on a bad plan.
read_issue_node
📋
2 · Plan
Sends issue + repo tree to Claude. Returns a structured TaskPlan: exact file paths, atomic tasks, acceptance criteria, breaking-change risk flags, and new pip dependencies. Max 5 tasks per plan.
plan_node · Claude Opus
⚡
3 · Code
Loads all planned files. Uses BM25 search to discover additional relevant files. Context is built using AST-aware token budgeting (tree-sitter) — functions are never split mid-definition. Claude generates a unified diff patch.
code_node · ContextBuilder · BM25
🧪
4 · Test
Applies the patch to a freshly cloned repo. Runs pytest inside a hardened Docker sandbox — network disabled, memory capped at 512MB, all Linux capabilities dropped. Parses structured JSON test reports.
test_node · Docker · pytest-json-report
🔄
5 · Self-Correct (up to 3×)
If tests fail, an error classifier determines the failure category. Claude receives the failure + the full attempt history (to prevent repeating mistakes) and generates a corrected patch. LangGraph checkpoints state after every node — crashes are resumable.
correct_node · error classifier · LangGraph checkpoints
🚀
6 · Open PR
Creates a branch, commits the patch, and opens a pull request with an LLM-generated description including test results and coverage. On persistent failure (all retries exhausted), opens a draft PR with a diagnostic summary for human review.
open_pr_node · PyGitHub
swe-agent — demo run (--dry-run)
Features

Production-Grade
From Day One

Every component built with the same standards you'd expect in a Fortune 500 production system.

🔒
Hardened Docker Sandbox
Network disabled. Memory capped. All Linux capabilities dropped. --security-opt no-new-privileges. Tests run in total isolation.
🧠
AST-Aware Context
tree-sitter parses Python files and builds token-budgeted context that never splits a function mid-definition. Better context → better patches.
🔁
Anti-Loop Self-Correction
Full attempt history is passed to each retry with explicit "DO NOT REPEAT" instructions. Error classification prevents the agent from cycling on the same mistake.
💾
Crash-Resumable Runs
LangGraph checkpoints agent state to PostgreSQL after every node. If the worker crashes mid-run, replay from the last checkpoint using the same run_id.
📊
Full Observability
Structured JSON logs (structlog), LangSmith tracing per node, 6 Prometheus metrics, Grafana dashboards, and per-request correlation IDs.
⚡
Redis + RQ Job Queue
HMAC-validated webhooks. Idempotency checks. Two priority queues. Sliding-window rate limiter. Workers scale horizontally with Docker Compose.
🔑
Security by Default
HMAC constant-time comparison. SecretStr for all credentials. HSTS, CSP, X-Frame-Options headers. Configurable TrustedHostMiddleware. Non-root containers.
🧪
80%+ Test Coverage
28 unit test files, 2 integration tests, a 10-case golden eval suite, and an enforced 80% coverage gate in CI. pytest + asyncio throughout.
